# Лабораторная работа №1  
Разработка клиент-серверного приложения с применением TCP-сокетов на Java

## Описание

Приложение реализует клиент-серверное взаимодействие через TCP-сокеты.

Клиент передаёт серверу координаты n-мерного вектора.
Сервер вычисляет длину вектора и отправляет результат обратно.

Реализованы две версии сервера:
- Последовательная обработка запросов
- Параллельная обработка запросов (многопоточность)

---

## Структура проекта

- VectorClient — клиентское приложение
- VectorServerSequential — сервер с последовательной обработкой
- VectorServerParallel — сервер с параллельной обработкой
- ClientHandler — обработчик клиента (Runnable)

---

## Формат передачи данных

Координаты передаются строкой через пробел:

```
1.0 2.0 3.0
```

Для завершения работы используется команда:

```
exit
```

---

## Используемые технологии

- Java 25.0.2
- TCP Socket
- Многопоточность (Thread)

---

## Как запустить

1. Запустить VectorServerSequential или VectorServerParallel
2. Затем запустить VectorClient
3. Ввести координаты вектора
